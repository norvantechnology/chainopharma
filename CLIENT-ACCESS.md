## Forgot password / OTP emails

Official sending email: **chainopharma@gmail.com**

If “Send OTP” or verification emails do not arrive:

1. Sign in to Google with `chainopharma@gmail.com`
2. Turn on **2-Step Verification**
3. Create an **App Password** (Google Account → Security → App passwords)
4. Share that 16-character App Password with your Chaino Pharma support person so they can update the server

Until that App Password is set, Google blocks the normal Gmail password for sending mail.
